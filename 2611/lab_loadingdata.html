Loading data into R


1 Introduction

So far, we’ve typed our data into R. Real data comes in files: from instruments, collaborators, databases. In this lab you will:

  • organise your files and use relative paths,
  • read text files with read.table(), read.csv(), read.csv2() and read.delim(),
  • describe a file to R: separator, decimal mark, missing values, comment lines,
  • check what you’ve read,
  • find and fix problems in broken files,
  • read Excel files,
  • write data to files,
  • explore a real genome annotation.

As always: predict first, then run. If the output surprises you, find out why. Click the key to reveal example code. Keep your code and notes in your R Markdown learning journal.

7 A real genome annotation

A GTF file describes where the genes, transcripts and exons of a genome are. It is a tab-separated text file with nine columns and no header:

# Column Content
1 seqname chromosome
2 source where the annotation comes from
3 feature gene, transcript, exon, CDS, …
4 start start position (1-based)
5 end end position
6 score a number, or .
7 strand + or -
8 frame 0, 1, 2, or .
9 attribute gene_id "..."; gene_name "..."; and more
  1. Download the Drosophila melanogaster annotation from Ensembl into data/. You don’t need to unzip it: R can read .gz files directly.
download.file("https://ftp.ensembl.org/pub/release-86/gtf/drosophila_melanogaster/Drosophila_melanogaster.BDGP6.86.gtf.gz",
              "data/Drosophila_melanogaster.BDGP6.86.gtf.gz", mode = "wb")
  1. Read the file with read.delim(). It has no header, its first lines are comments starting with #, and the attribute column contains quotes, so add quote = "". Give the columns meaningful names, then check the dimensions and structure.

gtf <- read.delim("data/Drosophila_melanogaster.BDGP6.86.gtf.gz",
                  header = FALSE, comment.char = "#", quote = "")
colnames(gtf) <- c("chromosome", "source", "feature", "start", "end",
