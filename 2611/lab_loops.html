Loops and functions


1 Introduction

Loops, decisions and functions let you write your analysis once and run it on any number of samples. In this lab you will:

  • repeat steps with for and while loops,
  • store loop results the efficient way,
  • compare loops with vectorised code,
  • make decisions with if, else if, else and ifelse(),
  • write your own functions, with default arguments and input checks,
  • combine all three.

As always: predict first, then run. If the output surprises you, find out why. Click the key to reveal example code. Keep your code and notes in your R Markdown learning journal.

  1. Write a function molarity() that calculates the concentration (mol/L) of a solution from the mass of compound (g), its molecular weight (g/mol) and the volume (L). It should stop with a clear error message if the volume is zero or negative. Test it: 5.844 g of NaCl (58.44 g/mol) in 0.5 L should give 0.2 mol/L.

molarity <- function(mass_g, mw, volume_l) {
  if (volume_l <= 0) {
    stop("volume_l must be positive")
  }
  (mass_g / mw) / volume_l
}

describe_columns <- function(df) {
  for (j in seq_along(df)) {
    column <- df[[j]]
    if (is.numeric(column)) {
      cat(names(df)[j], ": mean", mean(column), "\n")

    }
  }
}

5 All together

  1. The restriction enzyme DpnI cuts at the site GATC. Write a function count_site(dna, site) that counts how often site occurs in a DNA sequence. Use a for loop over every position, substr() to extract a piece of the same length as site, and if to check whether it matches. Test it on "GATCGATCAAGATC" (3 sites), then make site default to "GATC".

count_site <- function(dna, site = "GATC") {
  n <- 0
  len <- nchar(site)
  for (pos in 1:(nchar(dna) - len + 1)) {
    if (substr(dna, pos, pos + len - 1) == site) {
      n <- n + 1
    }
  }
  n
}
count_site("GATCGATCAAGATC")
count_site("GATCGATCAAGATC", site = "AAG")
## [1] 3
## [1] 1
