1 Introduction

Every value in R has a type, and the type decides what you can do with it: you can add two read counts, but not a read count and a gene name. In this lab you will practise the lecture’s topics using small examples from the lab bench. By the end you should be able to:

  • create values of the common data types and check their type,
  • convert between types on purpose (casting), and know that casting is not rounding,
  • recognise when R converts types for you (coercion), and why that can cause silent errors,
  • handle the special values Inf, NaN and NA,
  • use arithmetic, comparison and logical operators,
  • do basic text manipulation on gene names, sample IDs and DNA sequences.

1.1 Data types

The four data types you will use every day:

Type What it holds Lab example
double any number Ct value 24.1, temperature 37.5
integer whole numbers read count 1523L
character text gene "BRCA1", sample "S01"
logical TRUE or FALSE treated? TRUE

Numbers are stored as doubles by default, even whole numbers like 1523. Add L to get an integer: 1523L.
