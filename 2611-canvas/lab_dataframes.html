1 Introduction

Vectors hold one type in one dimension. Real data needs bigger containers:

Container Holds Example
matrix one type, rows × columns a plate of absorbance readings
data frame one type per column a patient table
list anything everything about one gene

In this lab you will:

  • create matrices, data frames and lists,
  • select values by position, name and condition,
  • calculate on rows and columns,
  • filter, extend and merge data frames,
  • deal with missing values,
  • get results out of lists.

As always: predict first, then run. If the output surprises you, find out why. Click the key to reveal example code. Keep your code and notes in your R Markdown learning journal.

2 Matrices

A 96-well plate is a matrix: rows A–H, columns 1–12. Here is a small part of one, with absorbance readings for 3 rows and 4 columns, read row by row:

              0.15, 0.51, 0.93, 0.06,

rownames(plate) <- c("A", "B", "C")
colnames(plate) <- 1:4
